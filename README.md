# せどりAI モバイル版（PWA）

iPhone / iPad / Android のホーム画面に追加して使える静的Webアプリです。

## 対象サイト
仕入候補の探索対象：
- メルカリ
- 楽天ラクマ
- Yahoo!フリマ
- Yahoo!オークション
- ジモティー
- モバオク

相場確認の補助：
- オークファン
- 各サイトの売切れ・落札履歴
- 中古専門店等の確認可能な公開相場

## 事前に用意するアカウント
質問送信・購入まで行う運用では、各サイトの本人用アカウントをユーザー自身で用意します。

- メルカリ：メルカリアカウント。新規登録時に本人情報の登録が必要。高額購入では本人確認を求められる場合あり。
- 楽天ラクマ：楽天IDとラクマアカウント。アプリ版のログインは楽天ID。日本国内在住者向け。
- Yahoo!フリマ：Yahoo! JAPAN ID、携帯電話番号設定・SMS認証。通常利用ではPayPayアカウント連携は必須ではない。
- Yahoo!オークション：Yahoo! JAPAN ID、携帯電話番号設定・SMS認証。取引を進める際はYahoo!ウォレット登録が必要。
- ジモティー：メールアドレスまたは対応SNSアカウント等で会員登録し、メールアドレス認証。機能・カテゴリによって本人確認が必要になる場合あり。
- モバオク：ユーザー情報登録と原則有料会員登録。Webの公式ガイドでは月額330円（税込）。
- オークファン：相場確認の補助。一般会員登録は無料。会員種別により利用可能な相場機能が異なる。

パスワード、2段階認証コード、カード番号などはGitHubに保存しません。

## 主な機能
- BUY / WATCH / PASS 自動判定
- 「仕入元」と「販売先」を分けて利益計算
- 販売手数料率を販売先ごとに自動初期設定し、実際の会員条件・キャンペーンに合わせて修正可能
- 予算5万円、予備費5千円、西宮市から50km条件
- 真贋リスク・状態リスク・比較件数を含む100点スコア
- WATCH / BUY候補に対して、カテゴリ・真贋・状態リスクに応じた出品者向け確認質問を自動生成
- 自動生成した質問文をワンタップでコピー
- 保存候補から質問文を再コピー可能
- 候補を端末内に保存（localStorage）
- CSV書き出し / 読み込み（質問文も保存対象）
- 複数サイトへの検索リンク
- オフライン利用対応（初回アクセス後）
- GitHub `data/market_history.json` に確認済み相場・判定データを蓄積する運用

## JARVIS運用ルール
ユーザーが開始を許可した時だけ外部サイト操作を開始します。

1. ログイン済みサイトを横断して候補を検索
2. 商品情報・画像・価格・状態を確認
3. 売切れ・落札・専門店等の相場を確認
4. 利益、利益率、真贋、状態、回転性を評価
5. BUY / WATCH / PASS を判定
6. 判定根拠と確認URLをGitHubの相場履歴へ蓄積
7. 情報不足なら出品者への質問案を作成
8. 質問送信前にユーザー確認
9. 出品者の返信を確認し、必要なら再質問案を作成
10. 返信・再質問の送信前にユーザー確認
11. 情報が揃ったら再判定してGitHubを更新
12. BUY候補の購入直前に、仕入価格・想定売価・利益・リスクを最終提示
13. 購入確定は必ずユーザーの明示同意後に実行

### 認証・安全
- パスワード、2段階認証コード、決済情報をGitHubへ保存しない
- 初回ログイン、再認証、CAPTCHA、本人確認などはユーザー操作が必要になる場合がある
- サイト側の規約、認証、利用制限を優先する
- 出品者への質問・返信送信は人の確認後
- 購入確定は人の最終同意後

## 販売手数料の初期値
- メルカリ: 10%
- Yahoo!フリマ: 5%
- 楽天ラクマ: 10%（実際は販売実績により4.5%〜10%で変動するため要修正）
- Yahoo!オークション: 10%（会員条件等で異なる場合は要修正）
- モバオク: 0%（月額会員費は固定費として別管理）
- ジモティー: オンライン5% / 現金手渡し0%

## iPhone / iPadで使う方法
このフォルダをHTTPS対応のWebサーバーへ公開します。公開URLをSafariで開き、共有ボタン →「ホーム画面に追加」でアプリ化できます。

GitHub Pages / Cloudflare Pages / Netlify などの静的ホスティングで公開できます。

## 注意
- 端末内保存なので、Safariのサイトデータを消すと候補履歴も消えます。重要な候補はCSVを書き出してください。
- 静的PWA単体では外部サイトへ自動ログイン・自動送信・自動購入は行いません。これらは許可されたブラウザ操作環境で行う運用です。
- 最終購入は必ず人間承認です。
